# 🌦️ Weather App

A simple and responsive weather app that shows live weather data of any city.

### ✨ Features
- Search weather by city name
- Shows temperature, humidity, wind speed
- Shows weather condition with icons (sunny, cloudy, rainy)
- Responsive design for mobile and desktop
- Handles invalid city name

### 🛠️ Tech Stack
- HTML, CSS, JavaScript
- OpenWeatherMap API
- VS Code

### 📂 Project Structure

### 🚀 How to Run
1. Clone the repo: `git clone https://github.com/shradhakalse/my-first-project.git`
2. Open `weather` folder in VS Code
3. Add your API key in `script.js`
4. Open `index.html` with Live Server

### 🔑 API Used
[OpenWeatherMap API](https://openweathermap.org/api)
